Set up Tana2D

Move Tana2D to Applications, then open it. The app includes its window engine and helper. You do not need to install another window manager.

Allow window control

Setup shows one step at a time and moves on by itself when a step is done. If Tana2D is not yet in Applications, choose Move to Applications first. On the permission step, choose Open Settings. In System Settings → Privacy & Security → Accessibility, enable Tana2D. If it is missing, use the plus button and select Tana2D in Applications. Return to Tana2D; its checklist updates automatically.

If macOS blocks the helper

Tana2D keeps windows live while placing them off screen and animating the overview. Those features require its helper inside Dock, which macOS normally protects. Keeping all features currently requires reduced System Integrity Protection (SIP). This weakens a system security boundary. Decide whether that tradeoff suits your Mac; a managed Mac may prohibit it.

Tana2D does not make these changes automatically. Installing the app is two steps; preparing a stock Mac requires the additional steps below. These instructions follow the helper foundation’s upstream requirements. Check that page for changes affecting your macOS version.

Setup walks through these steps with pictures, can print them, and offers to shut down for you. Tana2D reopens after you log back in so you can finish.

  1. Shut down. On Apple Silicon, hold the power button until startup options appear, then choose Options → Continue. On Intel, start while holding Command + R.
  2. In Recovery, open Utilities → Terminal.
  3. For Apple Silicon on macOS 14 or newer:
    csrutil enable --without fs --without debug --without nvram
    For Intel:
    csrutil disable --with kext --with dtrace --with nvram --with basesystem
  4. Restart and log in; Tana2D reopens. On Apple Silicon, choose Turn On and approve the password prompt: setup adds the -arm64e_preview_abi boot argument and keeps any existing arguments. Then choose Restart Now. To do it by hand instead, inspect any existing boot arguments first in Terminal:
    nvram boot-args
    If none are set, run:
    sudo nvram boot-args=-arm64e_preview_abi
    If there are existing arguments, preserve them and append -arm64e_preview_abi to the quoted value instead of replacing them. Restart again.
  5. Choose Install Helper and approve the macOS administrator prompt. After a short tour, choose Start Tana2D.

The helper setup installs Tana2D’s own files and a permission to reload only that fixed helper. It does not give Tana2D an unrestricted passwordless administrator shell. If setup still fails after a restart, the helper may not support your exact macOS version; Tana2D will keep setup open rather than move windows with a missing helper.

Other checklist items

Use one connected display. In System Settings → Desktop & Dock → Mission Control, enable Displays have separate Spaces; macOS may require logging out and back in. Quit another running window manager before starting Tana2D. Start on an ordinary desktop rather than in a full-screen app.

Keyboard, mouse, and screen readers

The Tana2D menu stays visible by default. Every command is available there and in the command palette. No trackpad is required. Choose Keyboard when setup asks how you like to work, or Keyboard & screen reader mode in Settings, for reduced motion, no hover focus or haptics, and ordinary Spotlight and app Quit shortcuts. The palette then uses Control + Command + P. macOS Reduce Motion, Increase Contrast, and Reduce Transparency are respected in Tana2D’s controls.

Use Option + Command + any arrow key to focus windows in that direction. Use three-finger swipes to pan and pinch to zoom. Use Control + Enter, Control + Up, or a four-finger swipe up to zoom out to the whole workspace; press the shortcut again or swipe four fingers down to return to the focused window at 100%. Applications stay usable while zoomed out; below 50% zoom, clicking a window zooms in on it at 100%. Hover focuses the window under the pointer immediately without changing zoom. Moving into a window already near the center can gently center it with an animation; passing over an edge or a distant window does not. Native input stays enabled during camera movement. Zoom preserves window sizes and ordinary mouse movement. Command + Enter opens a new Ghostty window; Command + Shift + W opens Firefox. Option + Command + 0 returns to actual size. VoiceOver can activate the menu and command palette. Shortcuts can be changed in the configuration file.

Start at login or stop

Open Tana2D when I log in is optional. macOS may ask you to allow it in Login Items. To stop managing windows, choose Quit Tana2D from its menu. Surviving tracked windows are restored.

Restore normal SIP protection

First disable Tana2D’s login item, quit it, and remove it and its helper using the installation guide. Return to Recovery Terminal, run csrutil enable, and restart. On Apple Silicon, remove only -arm64e_preview_abi from your boot arguments, preserving other arguments. If that was the only argument, sudo nvram -d boot-args removes the property. Restart again. Tana2D’s full window-management features cannot run with the helper blocked.
